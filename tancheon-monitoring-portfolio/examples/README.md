# 공개 참조 코드

2026-09-28 개발본의 독립적인 계산 로직을 선별했습니다.

| 파일 | 출처·공개 처리 | 범위 |
|---|---|---|
| [floating.py](floating.py) | 플랫폼의 `cctv/floating.py` 구현 | 비율 환산, 단계 판정, 누적 횟수 기반 단계 확정 |
| [risk.py](risk.py) | 플랫폼의 `cctv/risk.py`에서 최상단 설명만 공개용으로 정리 | 분 단위 평균, 제한된 결측 보완, 시계열·스캔 위상 특성, JSON 트리 계산 |
| [demo.py](demo.py) | 공개 확인용으로 새로 작성 | 합성 시계열·트리를 이용한 경계 조건 확인 |

## 실행

Python 3에서 표준 라이브러리만 사용합니다.

```bash
python demo.py
```

운영 API·DB·카메라에 접속하지 않습니다. 예제의 입력과 트리는 합성 값이며 모델 정확도나 현장 위험도를 보여주는 예제가 아닙니다.

## 제약

- 운영용 모델 JSON, 가중치, 카메라 메타데이터, 측정 로그는 포함하지 않습니다. 모델 로더는 파일이 없으면 `None`을 반환합니다.
- JSON 계산기는 이 프로젝트에서 쓰는 수치형 분기·특성 순서에 맞춘 구현입니다. 범주형 분기 등 모든 LightGBM 모델을 지원하지 않습니다.
- 단계 기준은 프로젝트 코드의 동작 설명이며 일반적인 수질·홍수 안전 기준이 아닙니다.
- 예제 검증 범위는 단계 경계, 결측 처리, 특성 순서와 합성 트리입니다. 운영 모델의 수치 일치·현장 성능을 검증하지 않습니다.
- 전체 서비스 실행에 필요한 인증·웹·DB 모듈은 공개 예제에 포함하지 않습니다.
