# TOVNET-SEG | CCTV 부유물·수면 영역 분석

![기술 인수 당시 프로젝트 개요](assets/slide-02.png)

정부과제 AI 결과물의 기술 인수·발표 경험과, 이후 저장소에 반영된 영상 추론·후처리·플랫폼 연동·재학습 실험을 정리합니다.

> **2026-09-29 업데이트:** 2026-09-28 개발본 기준. 원개발은 기존 기록상 성균관대학교 연구진 주도이며, 원모델을 개인이 처음부터 개발했다고 주장하지 않습니다. 최신 기능은 프로젝트 구현 범위로 기술합니다.

## 기술 인수 이후 확인한 개발 범위

| 영역 | 확인 내용 |
|---|---|
| 추론 | OneFormer + Swin-Large, PyTorch, 1080p 프레임의 아래쪽 패딩 후 단일 해상도 추론·크롭 |
| 구조 | 수집, 추론, 이벤트, 출력, 제어·스케줄링 모듈 분리 |
| 영상·출력 | RTSP/FFmpeg 입력과 HLS·웹 출력 모듈 |
| 학습 자료 선별 | 불확실한 픽셀 비율 계산 코드, 재학습·의사 라벨·평가 스크립트 |
| 재학습 검증 | 기존 모델과 v3 후보의 기존 시험셋·수작업 검증셋·오탐 사례 비교 결과 |
| 예측 | 부유물 시계열의 조기경보·면적 예측 실험 및 플랫폼 연계 코드 |
| 플랫폼 | AI 결과 수신, 측정 저장, 비율 차트, 이벤트·SSE·센서 통합 |

기존 문서의 수면 조류 설명에 더해, 최신 코드·평가에서는 슬러지와 녹조를 합친 부유물 영역을 다룹니다. 이를 일반적인 하천 수위·홍수 예측 성능으로 해석하지 않습니다.

## 파이프라인

```text
CCTV 프레임 수집
  → 전처리·스케줄링
  → OneFormer 추론
  → 마스크 후처리·비율 및 부가 특성 계산
  → 이벤트·DB·플랫폼 연계
  → HLS·웹 화면 및 통계 표시
```

현재 추론 코드에는 1920×1080 입력을 1920×1088로 패딩하고 결과를 원래 높이로 크롭하는 처리와 bfloat16 추론 경로가 있습니다. 임의 해상도·CPU 환경까지 검증했다고 주장하지 않습니다.

## 모델 평가와 해석

[평가 조건·상세 표](EVALUATION.md)와 [접속 경로를 제거한 집계 결과](evidence/retrain-v3-summary.json)를 함께 공개합니다.

| 평가셋 | 평가 프레임 | 기존 모델 부유물 IoU | v3 후보 부유물 IoU |
|---|---:|---:|---:|
| 기존 시험셋 | 124 | 0.4156 | 0.4817 |
| 수작업 검증셋 | 55 | 0.5492 | 0.7338 |
| 오탐 사례 holdout | 101 | 0.1214 | 0.2872 |

IoU는 정답에 부유물이 있는 프레임만의 평균입니다. 전체 클래스 mIoU와 다릅니다. 수작업 검증셋에서는 배경 픽셀 오탐률이 **0.695% → 1.749%**로 증가했습니다. 후보 모델의 운영 교체 완료나 모든 조건의 성능 향상을 뜻하지 않습니다.

## 예측 실험과 플랫폼 반영

예측 실험 폴더에는 persistence·기울기 기준선, Chronos, LightGBM 비교와 추가 실험 코드가 있습니다. 목적은 가까운 미래의 부유물 비율 임계 초과 및 면적 변화를 평가하는 것입니다.

최신 플랫폼 코드에는 최근 측정 이력으로 위험도·예상 면적을 계산하고 캐시해 표시하는 경로가 있습니다. 따라서 초기 실험 README의 “운영 코드와 무관”이라는 표현을 현재 전체 구현 상태로 그대로 쓰지 않습니다. 실험 코드와 서비스 연계 코드를 구분하고, 현장 예측 품질은 별도 검증 대상으로 둡니다.

## 엔지니어링 과제

- RTSP 연결·재연결과 FFmpeg 프로세스 수명 관리
- 입력 상태와 첫 추론 성공 상태 구분
- 입력 결측·수집 주기 변화·PTZ 이동에 따른 비율 변동 해석
- 학습과 서비스의 특성 순서·결측 처리 일치
- 이벤트 확정·재알림 제어, 센서와 영상 결과의 실시간 전달
- 재학습 시 검증셋별 오탐 증가 여부와 운영 적용 조건 확인

[탄천 통합 모니터링 상세](../tancheon-monitoring-portfolio/)에서 구현·실험·미완성 상태를 구분합니다.

## 공개 범위와 기여

원개발 연구진의 결과물, 기술 인수·분석·발표 경험, 이후 프로젝트의 구현과 실험 기록을 구분합니다. 원본 현장 영상, 학습 데이터, 체크포인트, 운영 접속정보는 포함하지 않습니다.
