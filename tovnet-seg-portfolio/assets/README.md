# Public portfolio assets

이 폴더에는 공개 허가를 받은 이미지와 직접 제작한 구조도만 추가합니다.

## 추천 이미지

1. 개인정보가 없는 TOVNET-SEG 데이터 흐름도
2. 원본 영상·정답 마스크·예측 마스크 비교 예시
3. 민감정보를 제거한 관제 화면
4. 재현시험 결과 그래프
5. 정부과제 발표 장면 또는 발표자료 일부(공개 허가 필요)

## 업로드 금지 정보

- 서버·VPN·DB IP
- 계정 및 비밀번호
- API 주소와 인증정보
- RTSP 카메라 URL
- 원본 데이터셋 파일명에 포함된 현장정보
- 비공개 정부과제 문서와 원본 코드
- 발표자료에 포함된 기관 내부정보

모든 화면 캡처는 브라우저 주소창, 탭, 북마크, 사용자 이름까지 확인한 뒤 공개합니다.
