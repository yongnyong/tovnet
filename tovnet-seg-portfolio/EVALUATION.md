# 재학습 v3 비교 결과

2026-09-28 개발본에 포함된 비교 결과 JSON과 평가 스크립트를 정적으로 확인해 정리했습니다. 이번 공개 업데이트에서 모델을 재학습하거나 GPU 평가를 다시 실행하지 않았습니다.

## 평가 조건

- 기존 모델과 v3 후보를 같은 전처리 경로로 비교: 1920×1080 리사이즈, 아래 8px 패딩, bfloat16, 클래스 argmax
- 예측 마스크에서 100px 미만 연결 요소 제거
- 기존 시험셋, 슬러지·녹조를 합친 수작업 라벨 검증셋, 오탐 사례의 날짜 기준 holdout 사용
- 오탐 사례 평가에는 스크립트의 영상 손상 필터가 적용됨
- IoU는 정답 부유물이 존재하는 프레임별 IoU 평균
- 배경 오탐률은 프레임별 ‘정답 배경 중 부유물로 예측한 픽셀 비율’을 평균한 값

## 해석과 한계

세 평가셋에서 기록된 부유물 IoU는 상승했습니다. 그러나 수작업 검증셋의 배경 오탐률은 증가했고, 평균 예측 면적도 **9.25% → 13.09%**로 변했습니다. 비율로 경보를 생성하는 플랫폼에서는 이 변화가 알림에 미치는 영향을 추가 확인해야 합니다.

이 수치는 전체 클래스 mIoU, 실시간 처리량 또는 모든 현장에 대한 정확도가 아닙니다. 자동 정리 라벨을 사용하는 오탐 사례와 수작업 라벨은 성격이 달라 하나의 점수로 합치지 않습니다. 원본 영상·라벨과 모델 가중치를 공개하지 않으므로 이 저장소만으로 동일 평가를 재현할 수는 없습니다.

집계 결과에는 원본 체크포인트 경로, 현장 장치 ID와 영상 파일명을 포함하지 않습니다. 모델 교체·배포 여부는 이 평가 기록만으로 확정하지 않습니다.
