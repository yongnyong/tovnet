# TOVNET-SEG 프로젝트 요약

## 프로젝트 한 줄 설명

CCTV 영상에서 수면 조류 영역을 픽셀 단위로 분할하고 점유율을 계산해 관제 플랫폼에 전달하는 정부과제 기반 비전 AI 시스템입니다.

## 역할 구분

- 원개발: 성균관대학교 연구진 주도
- 나의 참여: 기술자료 인수·분석, 정부과제 발표, 유지보수 검토
- 현재 활동: Raspberry Pi·멀티스펙트럼 카메라 현장 연동과 고도화 방향 학습

## 핵심 기술

- Python, PyTorch
- OneFormer, Swin Transformer
- Semantic Segmentation
- RTSP, FFmpeg
- Flask, HLS, MJPEG
- MySQL, Redis, REST API
- GPU 기반 실시간 영상 추론

## 나의 수행 내용

1. 모델 및 시스템 개발일지 검토
2. 데이터셋·모델·평가 지표 정리
3. CCTV 입력부터 관제 API까지 전체 흐름 분석
4. 정부과제 발표자료 구성 및 기술 내용 발표
5. 운영 장애와 기존 해결 이력 분석
6. 모델 재현시험 및 현장 고도화 항목 도출

## 포트폴리오 핵심 문장

성균관대학교 연구진이 주도 개발한 CCTV 기반 수면 조류 세그멘테이션 시스템을 정부과제 결과물로 인수하여 기술 구조를 분석하고 발표했습니다. 현재 모델 실행환경과 운영 파이프라인의 유지보수 항목을 검토하고, Raspberry Pi와 멀티스펙트럼 카메라를 활용한 탄천 현장 고도화 방향을 학습하고 있습니다.

## 공개 시 주의사항

- 원본 개발일지 업로드 금지
- 모델 가중치와 데이터셋 업로드 금지
- 서버·DB·VPN·API·RTSP 정보 공개 금지
- 문서에 기록된 성능은 재현 전까지 개인 성과로 표현하지 않음
