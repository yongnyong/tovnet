# TOVNET-SEG 발표 스크립트

안녕하세요. 정부과제로 개발된 CCTV 기반 수면 조류 세그멘테이션 시스템의 기술 인수와 발표, 유지보수 검토를 수행한 양호용입니다.

이 시스템은 RTSP CCTV 영상을 수집하고 OneFormer 기반 모델로 수면의 조류 영역을 분할한 뒤, 면적과 점유율을 계산하여 DB와 관제 플랫폼으로 전달합니다.

원개발은 성균관대학교 연구진이 주도했습니다. 저는 전달받은 모델과 개발 기록을 분석해 영상 입력부터 추론, 후처리, 이벤트 생성, 외부 전송까지 전체 파이프라인을 파악했고, 이를 정부과제 발표자료로 정리하여 직접 발표했습니다.

기술자료에는 DeepLabV3+, Fast-SCNN, OneFormer로 이어지는 모델 검토 과정이 기록되어 있습니다. 타일링 방식에서 Full Resolution 단일 추론으로 변경하면서 지연시간이 1,481밀리초에서 646밀리초로 감소한 결과도 확인했습니다. 이 수치는 원개발 자료의 결과이므로 제 단독 개발 성과로 주장하지 않고, 기술 인수와 분석 범위로 구분하고 있습니다.

운영 기록에서는 RTSP 재연결, 메모리 증가, 체크포인트 호환성, FFmpeg 프로세스 종료, 첫 추론 상태 동기화 문제를 확인했습니다. 이를 통해 현장 AI에서는 모델 정확도뿐 아니라 스트림 안정성, 메모리, 프로세스 관리와 장애 복구가 중요하다는 점을 배웠습니다.

현재는 시스템을 유지보수하면서 Raspberry Pi와 멀티스펙트럼 카메라를 탄천 현장에 연동하고, RGB 영상과 스펙트럼 정보를 함께 활용할 수 있는 발전 방향을 검토하고 있습니다.

저는 완성된 연구 결과를 단순히 사용하는 데 그치지 않고, 구조를 이해하고 운영 문제를 정리하며 다음 연구 단계로 연결할 수 있다는 점을 보여드리고 싶습니다.
