# TOVNET-SEG 발표 스크립트

## 1. 표지

안녕하세요. CCTV 기반 수면 조류 세그멘테이션 시스템 TOVNET-SEG의 기술 인수와 고도화 검토 경험을 소개할 양호용입니다.

이 시스템의 원모델과 초기 운영 시스템은 성균관대학교 연구진이 주도 개발했습니다. 저는 정부과제 참여 과정에서 결과물을 인수해 구조를 분석하고 발표했으며, 현재 유지보수와 현장 고도화 방향을 검토하고 있습니다.

## 2. 문제 정의

하천 CCTV를 사람이 계속 관찰하면 담당자마다 판단이 달라지고 이상 상황을 놓칠 수 있습니다. 이 프로젝트는 영상의 조류 영역을 픽셀 단위로 분할하고, 화면 점유율을 계산하여 관제 시스템에 전달하는 것을 목표로 합니다.

## 3. 데이터 흐름

CCTV의 RTSP 영상을 수집하고 최신 프레임을 GPU 서버에 전달합니다. OneFormer 모델이 조류 영역 마스크를 만들면 점유율을 계산하고, 임계값을 기준으로 이상 상태를 판단해 관제 API로 전송합니다.

## 4. 원개발 모델

인수 문서에는 DeepLabV3+, Fast-SCNN을 거쳐 OneFormer Swin-Large가 적용된 과정이 기록되어 있습니다. 데이터 수집과 라벨링, 모델 학습, 최초 추론 시스템 개발은 성균관대학교 연구진의 주도 영역입니다.

## 5. 나의 역할

저는 모델을 처음부터 개발했다고 주장하지 않습니다. 제가 수행한 역할은 개발일지를 읽고 모델과 운영 구조를 이해하는 것, 정부과제 발표를 위해 기술 내용을 정리하는 것, 그리고 인수 이후 유지보수와 발전 방향을 검토하는 것입니다.

## 6. 성능 기록

인수 문서에는 타일 추론을 전체 해상도 단일 추론으로 변경해 지연시간을 줄인 결과가 기록되어 있습니다. 다만 평가 범위와 일부 수치가 문서 안에서 완전히 일치하지 않기 때문에, 이 값은 원개발 기록으로만 소개하고 향후 동일한 환경에서 직접 재현할 계획입니다.

## 7. 운영 장애

개발일지를 분석하면서 현장 AI 시스템은 모델 정확도만으로 완성되지 않는다는 점을 배웠습니다. RTSP 재연결, 프레임 큐, 체크포인트 호환성, FFmpeg 프로세스 종료, DB 상태 동기화 같은 운영 문제가 실제 서비스 안정성을 좌우합니다.

## 8. 현장 고도화

현재 Raspberry Pi와 멀티스펙트럼 카메라를 연결해 탄천 현장 시스템에 적용하는 방향을 학습하고 있습니다. 먼저 장치와 RTSP 연결을 확인하고, RGB 영상과 스펙트럼 데이터를 비교한 뒤 기존 AI 서버 또는 엣지 추론 구조와 연결하는 것이 목표입니다.

## 9. 인턴과의 연결

이번 인턴을 통해 인수 문서로 학습한 비전 AI를 직접 모델 학습과 평가로 확장하고 싶습니다. 또한 기존 PHP·MySQL 개발 경험을 바탕으로 카메라, 엣지 디바이스, AI 서버와 웹 서비스를 연결하는 IoT 융합 역량을 키우고 싶습니다.

## 10. 마무리

저의 다음 목표는 원개발 결과를 그대로 소개하는 데 그치지 않고, 기준 환경에서 성능을 재현하고 탄천 현장의 실제 데이터를 분석하며 Raspberry Pi와 멀티스펙트럼 카메라를 연결하는 것입니다.

감사합니다.
