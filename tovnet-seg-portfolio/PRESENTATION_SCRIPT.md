# 발표 설명 — 중간발표까지, 그리고 이후

이 프로젝트는 TOVNET-SEG와 탄천 모니터링을 하나의 개발 과정으로 설명합니다.

첫 번째 단계는 중간발표까지입니다. 성균관대학교 연구진이 주도한 결과물을 기술 인수하며, CCTV 영상이 들어와 영역 분할 결과가 되기까지의 구조와 당시 벤치마크를 정리했습니다. 당시 Tiling과 Full Resolution의 비교 수치는 기존 발표의 기록이고, 최신 재학습 결과와 같은 실험은 아닙니다.

두 번째 단계에서는 현장에서 계속 관측하고 확인할 수 있는 시스템으로 확장됐습니다. 카메라 직접 접속 경로와 스트림 처리를 점검하고, 프레임마다 흔들리는 마스크에는 시간 후처리를 적용했습니다. ROI와 PTZ 이동도 다뤄 실제 부유물 변화와 관측 조건의 변화를 구분하려 했습니다.

분석 결과는 측정 이력으로 저장되고 차트와 실시간 화면으로 연결됩니다. 예측도 실험 코드에서 출발해 30분 내 경계 도달 확률과 30분 뒤 예상 면적을 계산해 표시하는 경로로 이어졌습니다. 데이터와 모델이 충분한 경우의 구현이며 현장 품질 검증은 별도로 봅니다.

재학습은 v1에서 v3까지 진행한 기록을 비교했습니다. 세 평가셋의 부유물 IoU는 올랐지만 수작업 검증셋의 오탐률도 증가했습니다. 그래서 성능이 무조건 좋아졌다고 말하기보다, 면적 표시와 경보에 어떤 영향을 줄지 함께 설명합니다.

센서 수집·SSE·알림 연계도 같은 플랫폼에 포함됩니다. 센서 수집과 임계 경보, 알림 코드와 실제 운영 검증, 모델 후보와 배포 완료를 구분했습니다.

제 기술 인수·분석·발표 경험과 프로젝트 전체의 후속 구현을 나눠 설명하며, 원모델과 최신 기능 전체를 개인 단독 성과로 주장하지 않습니다. 이 포트폴리오는 별도 프로젝트를 늘리는 방식보다, 하나의 시스템이 어떻게 발전했는지를 보여주는 데 초점을 두었습니다.
