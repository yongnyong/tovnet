# 발표 설명 — 중간발표까지, 그리고 이후

안녕하세요. 토브넷에서 탄천 AI 영상 분석·모니터링 시스템의 전체 설계와 개발을 담당한 양호용입니다.

중간발표 전부터 시스템 코드를 직접 작성했습니다. 발표 이후에도 코드 전반을 검토하고 대부분의 구현을 수정·재구성하며 현장 요구에 맞게 개선해 왔습니다. 두 단계는 제가 개발을 시작한 시점을 나누는 것이 아니라, 직접 개발한 시스템의 진행 과정을 보여줍니다.

이 프로젝트에서는 CCTV 영상 수집부터 AI 분석, 측정값 저장, 예측, 웹 모니터링까지 전체 흐름을 직접 구현했습니다. OneFormer·Swin 등 기반 기술을 활용해 현장에서 필요한 분석 파이프라인과 서비스를 개발했습니다.

첫 번째 단계는 중간발표까지입니다. 영상 입력과 전처리, 모델 추론, 결과 처리와 현장 연결을 구현하고 처리 방식에 따른 성능을 비교했습니다. 당시 Tiling과 Full Resolution의 비교 수치는 기존 발표 기록이며 최신 재학습 평가와는 조건이 다릅니다.

두 번째 단계에서는 현장 조건에 맞춰 시스템을 확장했습니다. 프레임마다 흔들리는 마스크에 시간 후처리를 적용하고, ROI와 PTZ 이동을 고려해 비율을 계산했습니다. 스트림·스냅샷과 실시간 화면 갱신도 개선했습니다.

측정 이력을 저장해 차트로 보여주고, 30분 내 부유물 비율의 경계 도달 확률과 30분 뒤 예상 면적을 계산하는 기능을 웹 화면에 연결했습니다. 센서 수집과 SSE 전달, 알림 연계도 같은 플랫폼 안에서 개발했습니다.

모델 재학습과 비교 평가도 수행했습니다. v3 후보는 세 평가셋에서 부유물 IoU가 상승했지만, 수작업 검증셋의 배경 오탐률도 증가했습니다. 면적 표시와 경보에 미치는 영향을 함께 확인하는 것이 중요했습니다.

이 포트폴리오는 제가 전체 개발을 담당한 하나의 시스템이 중간발표 전후로 어떻게 발전했는지 보여줍니다. 센서 임계 경보·일부 통계처럼 남은 작업과 실제 배포·현장 검증 여부는 구현 결과와 구분해 설명합니다.
