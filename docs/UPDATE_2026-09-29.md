## MES: 최신 로컬 v2를 기준으로 갱신

기존 private Git 스냅샷만으로 설명했던 범위를 ALDrive로 내려받은 v2 소스와 대조했습니다. 루트 PHP 94개 중 기존 Git 대비 신규 32개, 줄바꿈을 정규화해도 달라진 파일 33개, 줄바꿈만 다른 파일 29개를 확인했습니다. 다운로드 시각을 기능 개발일로 해석하지 않았습니다.

영업·계약·분할 수금·계산서 일정, 생산요청·BOM·S/N, 설치·유심 이력, 메일·작업지시·Task·주간 보고, 부서별 대시보드를 반영했습니다. 자체 CSS/JS와 Bootstrap 5가 혼용되므로 이전의 Bootstrap 미사용 설명을 수정했습니다.

## TOVNET-SEG와 탄천을 하나의 개발 과정으로 통합

AI 영상 분석 시스템 개발, 재학습, 탄천 플랫폼, 현장 네트워크를 [하나의 포트폴리오](../tovnet-seg-portfolio/README.md)에서 1. 중간발표까지 / 2. 중간발표 이후로 설명합니다. 기존 발표자료를 1단계의 기준으로 삼았으며 정확한 발표 날짜는 지정하지 않았습니다.

별도 통합 모니터링 디렉터리의 계산 예제는 TOVNET-SEG 아래로 이동했습니다. 이전 네트워크 자료 경로는 보존하고 통합 문서로 연결했습니다. PDF·PPTX는 당시 기록으로 보존했습니다.

## 공개 범위와 확인

문서는 최신 코드와 저장된 평가 결과를 근거로 작성했습니다. 원본 운영 소스·접속 설정·고객 및 사내 데이터는 public 저장소에 복사하지 않았습니다. 모델의 재학습·GPU 평가·실서비스 연결 테스트를 새로 실행한 것은 아닙니다.

수작업 검증셋에서 IoU와 함께 오탐률도 상승한 점, 센서 임계 경보·일부 통계의 미완성 상태, MES의 위치 재고·총재고 연동 확인 필요성을 남겼습니다.

## 탄천 개발 역할 정정

탄천 AI 영상 분석·모니터링 시스템은 양호용이 전체 설계·개발을 담당했습니다. 기존 문서가 역할을 기술 인수·분석 중심으로 한정한 설명을 수정하고, 영상 수집·추론·후처리·재학습·평가부터 측정 저장·예측·웹 모니터링·센서·알림 연계까지 직접 개발한 범위를 반영했습니다. 기반 모델·라이브러리의 출처와 시스템 개발 역할은 구분합니다.
