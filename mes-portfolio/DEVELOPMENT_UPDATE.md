# MES 개발 업데이트

기준일: 2026-09-29 / 검토 대상 개발본: 2026-08-26

## 업무 범위 확장

기존 MAIN/SUB 업무·주간보고·고객 A/S·칸반과 제조·재고 기능에 영업 계약, 유지보수 SLA, RMA, 출하·견적, 유심 및 사내 메일 기능이 포함된 버전입니다.

### 거래처와 계약을 분리한 영업관리

`sales_log.php`는 거래처 아래 여러 계약을 두고, 각 계약에 영업단계와 메모·활동 기록을 연결합니다. 계약명·예상 금액·수량·시작일·예상 종료일·상태를 관리하며, 기존 거래처 단위 기록을 계약에 연결하는 데이터 보정 코드가 있습니다.

### A/S 이후 처리 확장

`rma_admin.php`는 고객·시리얼·A/S 접수와 반품/교환 요청을 연결합니다. `maintenance_sla.php`는 유지보수 계약 기간·등급·금액·상태를 관리합니다. 접수 기록 외에 계약과 후속 처리 이력을 관리하는 범위로 확장됐습니다.

### 유심과 사내 협업

MES 내부 유심 모듈은 고객·장치·유심 데이터와 상태를 관리하는 PHP 구현입니다. 별도로 공개돼 있는 [Laravel USIM 포트폴리오](../usim-management-portfolio/)와 동일 코드로 취급하지 않습니다.

POP3 동기화 코드는 계정별 메일 수집, 메시지 중복 확인, 메일함 저장을 수행합니다. 메일 기능의 코드 존재를 전체 발송·수신 동작 검증이나 보안 검수 완료로 표현하지 않습니다. 실제 메일 계정·본문·첨부파일은 공개하지 않습니다.

## 기술 설명 정정

최신 개발 문서 기준으로 PHP 8 + PDO, MariaDB/MySQL, 순수 HTML/CSS/JS, flatpickr 및 자체 모달 구성입니다. 이전 발표자료의 Bootstrap 설명을 최신 구현 설명에 그대로 적용하지 않습니다.

로그인 코드에서는 CSRF 토큰 비교, 비밀번호 해시 검증, 활성 계정 확인, 세션 ID 재발급, 감사 로그 처리를 확인했습니다. 이는 확인한 구현 항목이며 모든 엔드포인트의 보안 완성을 의미하지 않습니다.

## 확인 범위와 공개 방식

- 저장소 목록·개발 문서와 주요 기능 파일을 정적으로 확인했습니다. 운영 서버·DB·FTP에는 접속하거나 변경하지 않았습니다.
- 기존 개인 중심 역할(업무공유·주간보고·A/S), 사수 주도 제조 영역, 공동 프로젝트 관리 구분을 유지합니다.
- DB 연결 설정과 업무 업로드 자료가 섞인 원본 전체를 공개 저장소로 복사하지 않았습니다.
- 최신 DB 스키마·합성 데이터·실행 환경을 갖춘 MES 데모는 이번 업데이트 범위에 포함하지 않습니다.
