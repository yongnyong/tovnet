# MES 발표 설명 — 초기 기반에서 최신 v2까지

안녕하세요. 제조와 사내 업무를 연결하는 MES 개발에 참여한 양호용입니다.

처음에는 MAIN/SUB 업무, 주간보고, 고객 A/S, 프로젝트 칸반과 제조·재고 데이터를 하나의 시스템에서 관리하는 것이 중심이었습니다. 최신 v2는 영업건에서 계약·생산·납품·설치·수금까지 이어지는 흐름으로 확장됐습니다.

예를 들어 영업 담당자가 계약 품목으로 생산을 요청하면, 생산완료 코드가 BOM 재고를 차감하고 완제품 재고와 시리얼을 등록합니다. 이 시리얼은 조회 화면과 유심 관리로 연결되고, 설치 완료 기록은 연결된 유심의 설치일·담당자에 반영됩니다.

영업에서는 견적·계약·납품 문서 외에 계산서 발행 예정과 실제 입금을 구분합니다. 분할 입금 계획과 실제 수금 기록으로 잔액을 계산하고, 국내·해외의 미발행·미수·예정 현황을 모아 보여줍니다.

협업도 연결했습니다. 메일을 업무협조로 전달하고, 화면의 항목을 Task로 올려 주간보고로 이어갑니다. 주간 영업회의는 계산서·입금·배송·설치·A/S·대여 현황을 취합하고 담당자가 현황과 다음 할 일을 더하는 방식입니다.

기술적으로 PHP·PDO·MySQL/MariaDB를 사용하며, 최신 화면은 자체 CSS/JS와 일부 Bootstrap 화면이 함께 있습니다. 품목·반제품 BOM, 위치 재고와 변경 이력도 확장돼 있습니다.

역할은 구분해서 말씀드리겠습니다. 기존 협업에서 저는 업무공유·주간보고·A/S 흐름을 중심으로 참여했고 제조 프로세스는 사수가 주도했습니다. 프로젝트 관리는 공동 영역입니다. 이번 포트폴리오에는 최신 프로젝트 전체의 발전 과정을 담았으며 모든 기능을 개인 단독 성과로 주장하지 않습니다.

현재 설명은 최신 다운로드 소스를 읽어 확인한 범위입니다. 실제 운영 DB의 전 기능 시험과 위치 재고의 모든 경로 일치 등은 별도 확인 대상입니다.
