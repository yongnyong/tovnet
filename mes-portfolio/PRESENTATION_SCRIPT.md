# MES 포트폴리오 발표 스크립트

안녕하세요. PHP 기반 제조·업무공유·고객 A/S 통합 관리 플랫폼을 개발하고 있는 양호용입니다.

이 프로젝트는 제품과 부품, BOM, 재고, 시리얼 번호 같은 제조 정보뿐 아니라 사내 업무 공유, 주간보고, 고객 A/S 기록까지 하나의 웹 시스템에서 연결하는 것을 목표로 합니다.

기술적으로는 PHP와 MySQL을 중심으로 구성했고, 화면은 Bootstrap 5와 JavaScript Fetch API를 활용했습니다. 데이터베이스 연결에는 PDO와 Prepared Statement를 적용했으며, 로그인 세션, 비밀번호 해시, CSRF 같은 기본 보안도 고려했습니다. 재고처럼 동시에 변경될 수 있는 데이터에는 트랜잭션과 행 잠금 방식이 사용되었습니다.

역할은 명확히 구분해 설명드리겠습니다. 제조업체 근무 경험이 있는 사수는 공장 납품, 시리얼 번호, 생산과 재고 등 제조 프로세스를 주도했습니다. 저는 MAIN/SUB 업무 구조, 담당자와 상태 관리, 주간보고 연결 같은 업무공유 프로세스와 고객 A/S 흐름을 중심으로 참여했습니다. 프로젝트 관리 기능은 사수와 함께 우선순위와 진행 방식을 논의하며 공동 개발하고 있습니다.

현재는 주요 화면과 로직을 구현한 뒤 실제 사용 흐름에 맞게 권한, 입력 항목, 예외 처리와 데이터 연결을 보완하는 단계입니다. Git을 사용해 사수와 변경사항을 공유하고 기능을 통합하고 있습니다.

이 프로젝트를 통해 현장 담당자의 언어를 시스템 요구사항으로 바꾸고, 프론트엔드와 백엔드, 데이터베이스가 연결된 서비스를 함께 개발하는 경험을 쌓았습니다.
