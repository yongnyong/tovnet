## Project 2. TOVNET-SEG 수면 조류 세그멘테이션 시스템

**프로젝트 성격:** 정부과제  
**현재 역할:** 기술 인수·검토, 과제 발표, 유지보수 및 고도화 방향 검토  
**원개발:** 성균관대학교 연구진 주도  
**관련 기술:** Python, PyTorch, OneFormer, Swin Transformer, RTSP, FFmpeg, Flask, MySQL, Redis, REST API

### 프로젝트 목적

CCTV 영상에서 수면의 조류·부유 영역을 픽셀 단위로 분할하고, 화면 내 점유율을 계산하여 임계값 초과 시 관제 플랫폼에 이상 상태를 전달하는 시스템입니다.

```text
CCTV RTSP 스트림
        ↓
프레임 수집·전처리
        ↓
GPU 기반 세그멘테이션 추론
        ↓
조류 마스크·점유율 계산
        ↓
이상 상태 판단
        ↓
캐시·REST API·관제 화면 연동
```

### 원개발 시스템에서 확인한 내용

- 1,238쌍의 RGB 원본 영상과 이진 마스크 데이터 구성
- 학습·검증·테스트 데이터 분리
- DeepLabV3+, Fast-SCNN 검토 후 OneFormer Swin-Large 적용
- OneFormer 체크포인트와 PyTorch 추론 파이프라인
- IoU, F1-score, Pixel Accuracy 기반 평가
- RTSP 다중 스트림 수집과 GPU 추론
- MySQL·Redis·REST API를 통한 관제 플랫폼 연동
- Flask·MJPEG·HLS 기반 결과 모니터링 구조

> 위 모델 학습과 원시스템 구현은 성균관대학교 연구진이 주도했습니다. 이 저장소에서는 이를 개인 개발 성과로 주장하지 않습니다.

### 나의 참여 내용

- 정부과제 결과물의 모델 개발일지와 시스템 개발일지 검토
- OneFormer 기반 세그멘테이션 목적·입출력·평가 방식 학습
- RTSP 입력부터 추론, 점유율 계산, 관제 API 전송까지의 데이터 흐름 분석
- 정부과제 발표를 위해 기술 내용과 현장 적용 구조를 정리하고 전달
- 운영 장애 및 유지보수 기록 검토
- 새로운 현장·카메라 환경에 적용하기 위한 고도화 방향 조사

### 유지보수 관점에서 검토한 문제

- RTSP 재연결 시 프레임 큐 누적으로 발생할 수 있는 메모리 증가
- 모델 체크포인트와 라이브러리 버전 불일치
- FFmpeg 자식 프로세스의 종료·자원 정리 문제
- API 주소와 환경설정의 하드코딩
- 카메라 연결 상태와 실제 첫 추론 성공 상태의 차이
- 계절, 조명, 반사광 및 카메라 변경으로 발생하는 Domain Shift

### 고도화 방향

- 탄천 현장 데이터로 기존 모델의 성능 재평가
- RGB CCTV와 멀티스펙트럼 카메라 데이터 비교
- 오탐이 발생하는 반사광·그림자·저조도 데이터를 추가 수집
- Hard Example Mining과 추가 파인튜닝 검토
- 연속 프레임을 이용한 결과 안정화
- ONNX/TensorRT 또는 경량 모델을 이용한 엣지 추론 가능성 검토
- 모델·데이터셋 버전과 재현 가능한 평가 절차 정립

> 개발일지의 일부 성능 수치는 평가 범위가 서로 다르게 기록되어 있어, 현재 재현시험 전 단계에서는 개인 성과 수치로 사용하지 않았습니다.

## Project 3. Raspberry Pi · 멀티스펙트럼 카메라 현장 연동

**개발 상태:** 학습 및 연동 진행 중  
**적용 대상:** 탄천 현장 시스템

### 현재 진행 내용

- Raspberry Pi 기반 카메라 연결 구조 검토
- RTSP 영상 스트림 구동 방법 확인
- 멀티스펙트럼 카메라 조립 및 연동 준비
- 스펙트럼별 영상 데이터의 특성과 분석 방법 학습
- 기존 TOVNET-SEG 관제 시스템과의 연동 방식 검토

### 목표 구조

```text
멀티스펙트럼 카메라
        ↓
Raspberry Pi 영상 취득·전송
        ↓
AI 서버 분석 또는 엣지 추론
        ↓
탄천 관제 플랫폼 결과 연동
```

아직 모델 학습이나 분석 시스템을 완성한 단계는 아닙니다. 장치 구동과 데이터 특성을 익히고, 현장에서 취득한 데이터를 기존 AI 시스템에 활용할 수 있는 방법을 찾고 있습니다.
