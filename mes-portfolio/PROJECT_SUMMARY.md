# MES 프로젝트 요약

## 프로젝트명
PHP 기반 제조·업무공유·고객 A/S 통합 관리 플랫폼

## 목적
제품, 부품, BOM, 재고, 시리얼 번호 등 제조 정보와 사내 업무 공유, 주간보고, 고객 A/S 이력을 하나의 웹 시스템에서 연결·추적한다.

## 기술 구성
- Frontend: HTML, CSS, Bootstrap 5, JavaScript, Fetch API
- Backend: PHP, Session
- Database: MySQL, PDO, Prepared Statement
- Collaboration: Git
- Security/Data Integrity: 비밀번호 해시, CSRF, Transaction, `SELECT ... FOR UPDATE`

## 주요 기능
- 제품·부품·BOM·소모품 기준정보 관리
- 창고·재고·완제품·생산·불량 관리
- 시리얼 번호 조회와 제조 이력 추적
- MAIN/SUB 업무, 담당자, 상태, 진척도, 댓글, 첨부파일 관리
- 업무 데이터를 활용한 주간보고 작성
- 고객·판매·A/S 업무 흐름 관리
- 칸반 기반 프로젝트·세부 업무 관리
- 사용자·부서·권한·감사 로그 관리

## 역할 구분
- 사수 주도: 공장 납품, 시리얼 번호, 생산·재고 프로세스 정의
- 양호용 중심: 업무공유 프로세스와 고객 A/S 흐름 설계·개선
- 공동 개발: 프로젝트 관리 기능, 우선순위 협의, Git 기반 통합

코드에 작성자 표기가 없으므로 위 역할은 사용자가 확인한 범위만 기록하며 개별 파일의 단독 소유권은 주장하지 않는다.

## 현재 상태
현재 개발 중이다. 주요 화면과 핵심 로직을 구현하면서 권한별 사용성, 입력 흐름, 데이터 연결, 예외 처리, 현장 피드백 반영을 계속 보완하고 있다.

## 포트폴리오 한 줄
제조 도메인 전문가인 사수와 협업하여 PHP·MySQL 기반 MES를 개발하고, 업무공유·주간보고·고객 A/S 프로세스를 중심으로 실제 현장 업무를 웹 시스템 흐름으로 구체화했다.
